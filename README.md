# LeetDock

LeetDock is a Visual Studio Code extension focused on solving problems from
[LeetCode China](https://leetcode.cn) without leaving the editor.

The first release supports secure browser sign-in, problem search and viewing,
local solution files, language switching, and recently opened problems.

## Development

```shell
npm install
npm run check
npm run compile
```

Interactive sign-in and Webview acceptance checks require a desktop VS Code
instance and a browser.
